# ESP32-ETH01: Wi‑Fi → LAN роутер

Прошивка для платы **ESP32-ETH01 V1.4 / WT32-ETH01 с LAN8720**. Она подключается к существующей Wi‑Fi сети как клиент и раздаёт интернет в Ethernet-разъём платы. На Ethernet включены NAT и DHCP, поэтому старый Xbox подключается обычным кабелем и получает адрес автоматически.

## Быстрый запуск

1. Прошейте три файла из каталога [`firmware/`](firmware/):
   - `bootloader.bin` по адресу `0x1000`;
   - `partition-table.bin` по адресу `0x8000`;
   - `ota_data_initial.bin` по адресу `0xf000`;
   - `esp32_eth_router.bin` по адресу `0x20000`.
2. Подключите Ethernet кабель от платы к Xbox/тестовой машине.
3. Откройте `http://192.168.4.1`.
4. На странице **Configuration** укажите Wi‑Fi SSID/пароль точки НЕВОД и сохраните. После перезагрузки плата подключится к Wi‑Fi.
5. На странице **Status/Mappings** видны состояние uplink, Ethernet IP, диапазон DHCP и выданные leases.

Пароль веб‑панели задаётся в разделе **Web UI Settings**. До установки пароля панель доступна только из вашей Ethernet-сети.

## Параметры LAN по умолчанию

- IP роутера: `192.168.4.1/24`
- DHCP: включён
- Пул: `192.168.4.2`…`192.168.4.101`
- DNS и шлюз для клиента: `192.168.4.1`
- NAT: включён

Если Xbox не получает DHCP, вручную задайте:

- IP: `192.168.4.10`
- Маска: `255.255.255.0`
- Шлюз: `192.168.4.1`
- DNS: `192.168.4.1` (или DNS, показанный на странице Status)

## Прошивка из терминала

```bash
./flash.sh /dev/cu.usbserial-XXXX
```

Скрипт использует `esptool`, стирает старую конфигурацию только если запрошено явно (`ERASE=1`), и прошивает бинарники с правильными адресами. После первого запуска настройки сохраняются в NVS.

## Аппаратная конфигурация

Для ESP32-ETH01 V1.4 используется LAN8720 RMII:

- MDC GPIO23
- MDIO GPIO18
- PHY address 1
- PHY power GPIO16
- RMII clock GPIO0

Проект основан на [martin-ger/esp32_ethernet_router](https://github.com/martin-ger/esp32_ethernet_router); исходный код и лицензия сохранены.
